# 給与計算（実打刻ベース）

オーナー管理画面でスタッフの月次給与を計算する。打刻（LINEの出勤〜退勤＝time_records）を
元データに、休憩・残業・深夜を反映して**総支給（額面）**まで算出する。

## 計算ルール（`src/lib/payroll.ts` の `computePayroll`）

- **集計元**：`time_records`（clock_in〜clock_out, JST）。退勤未打刻は「打刻中」として給与に含めない。
- **時給は日付で決まる（期間別・全員一律）**：`WAGE_SCHEDULE`（`src/lib/payroll.ts`）。
  - 6/8〜6/19 → ¥1,060 ／ 6/20〜7/31 → ¥1,600。範囲外の日は各自の `hourly_wage`（fallback）。
  - 時給が日によって変わるため、賃金は**日ごとに計算して合算**（`wageForDate`）。
- **休憩自動控除**（その日の実働合計に対して）：8時間超→60分 / 6時間超→45分 を差し引く。
- **端数（15分単位）**：休憩控除後の実働を**1日ごとに15分単位で四捨五入**してから賃金計算する
  （`round15`）。深夜分も同様に15分単位で四捨五入。残業判定もこの丸め後の実働で行う。
- **残業**：1日の実働（休憩控除＋15分丸め後）が8時間を超えた分を 1.25倍（割増 +0.25）。
  - 判定は**1日8時間超のみ**（週40時間超の残業は未対応）。
- **深夜**：22:00〜翌5:00(JST) の労働に +0.25 加算（`nightMinutes` で区間重なりを算出）。
  - 深夜かつ残業が重なる時間は 基本1.0＋残業0.25＋深夜0.25＝**1.5倍**相当。
- **総支給** = 基本(全労働×時給) + 残業割増 + 深夜割増 + **交通費(月額)**。
  - 源泉徴収・社会保険などの控除は未対応（額面まで）。
- 賃金は分単位で集計し、最後に円へ四捨五入。
- **週平均（社保判定の目安）**：月内の各週（月〜日）の実働合計を、勤務のあった週数で平均
  （`avgWeeklyMin`）。一覧に `週平均` 列として表示し、目安タグを付ける。
  - `社保`＝週30時間以上（一般被保険者の3/4基準に該当の可能性）。
  - `短時間?`＝週20時間以上（短時間労働者の特例。月額賃金¥88,000以上・2か月超の雇用見込み・
    学生でない・特定適用事業所(従業員規模)など他要件も要確認）。
  - あくまで目安。最終判断は社労士等に確認すること。

> ⚠️ 労基法は本来1分単位での支払いが原則で、行政通達で認められる丸めは「1か月の合計で
> 30分未満切捨・30分以上切上」。本システムの「日ごと15分・四捨五入」は四捨五入のため
> 切り捨て一辺倒よりは安全だが、運用上の合意のうえで採用している。

## 画面・導線

- 管理ナビ「給与計算」→ `/admin/payroll`。月セレクタで対象月を切替。
- スタッフ別の集計表（実働/残業/深夜/基本/各割増/交通費/総支給）と、
  名前をタップで開く**日別明細**（出退勤・実働・休憩・残業・深夜）。
- **時給・交通費（月額）は「スタッフ管理」→ スタッフ編集**で設定（`hourly_wage` / `commute_allowance`）。
